# Computer Forensics

This repository contains computer forensic investigations, artifact analysis exercises, and DFIR case studies completed as part of my practical digital forensics training. The work focuses on identifying, preserving, examining, and analyzing digital evidence from Windows systems using forensically sound methodologies.

## Repository Contents

* Windows artifact analysis
* Registry analysis
* Browser forensic analysis
* USB device investigations
* File system analysis
* Timeline reconstruction
* Memory forensics exercises
* Forensic reporting examples

## Tools Used

* FTK Imager
* Autopsy
* Magnet AXIOM
* KAPE
* Volatility 3
* MFTECmd
* Python (supporting analysis scripts)

## Objective

The goal of this repository is to demonstrate hands-on computer forensics skills, evidence handling procedures, timeline analysis, and professional forensic reporting suitable for DFIR and digital forensic analyst roles.

## Disclaimer

All investigations in this repository are conducted on training datasets, lab environments, or authorized evidence sources for educational and professional portfolio purposes.
