## Overview

This exercise involved recovering and cracking the password hash from a protected PDF file named `logs_protected.pdf`. The file was provided by **@redhadpentester of @hiveconsult** as a practical password-recovery challenge.

The investigation documented the full workflow from initial tool selection through successful password recovery. During the process, several important lessons were learned regarding file-type identification, correct hash extraction methods, shell handling of special characters, and PDF hash-mode selection in Hashcat.

The objective was to extract the password hash from the protected PDF, determine the appropriate cracking mode, recover the password using a wordlist attack, and verify successful access to the document.

## Initial Tool Selection

I first attempted to extract a hash using:

```bash
office2john logs_protected.pdf
```

The command returned:

```text
logs_protected.pdf : Invalid OLE file
```

This demonstrated that **office2john** is intended for Microsoft Office documents such as Word, Excel, and PowerPoint files, not PDF files.

## Hash Preservation

The extracted hash was saved to a text file for reuse during cracking.

Command used:

```bash
echo 'HASH_VALUE' > pdf_hash.txt
```

I intentionally used **single quotes** because characters such as `$` and `*` may be interpreted by the shell when double quotes are used.

To verify the saved hash, I used:

```bash
cat pdf_hash.txt
```

I also learned that the **entire hash string** generated by pdf2john must be saved, not only the hexadecimal portion.

To identify the PDF encryption details, I used:


## Hashcat Testing

Because the initially selected mode did not work, I tested the hash against the different PDF modes returned by:

```bash
hashcat --help | grep -i pdf
```

This confirmed that choosing the wrong mode prevents recovery even when the correct password exists in the wordlist.

## Password Recovery

The hash was eventually cracked using a different PDF hash mode.

Example command:

```bash
hashcat -m [HASH_MODE] pdf_hash.txt wordlist.txt
```

To display the recovered password, I used:

```bash
hashcat -m [HASH_MODE] pdf_hash.txt --show
```

## Lessons Learned

- File type must be identified before selecting a hash-extraction tool.
- `office2john` is not suitable for PDF files.
- `pdf2john.py` is the correct extraction tool for protected PDFs.
- Save the **full extracted hash**, not a partial value.
- Use **single quotes** when saving hashes containing shell-sensitive characters.
- Verify saved hashes before cracking.
- Selecting the correct Hashcat mode is critical.
- `pdfinfo` can assist with identifying PDF encryption details.
- Practical testing may still be required when mode identification is uncertain.
